# Разбор проекта и дальнейшие улучшения

## Исправлено в версии 2.0

Исходный редактор сохранял большую HTML-строку в IndexedDB. Сохранение зависело от ручного действия; галочка меняла свойство DOM без изменения сохраняемого HTML. Поэтому текст мог теряться при переключении страниц, а галочки — сбрасываться после перезапуска.

Теперь изменения сохраняются автоматически, переключение и закрытие ждут записи, а состояние галочек попадает в сохранённое содержимое. На Windows страницы и вложения лежат в отдельной папке, которую можно перенести целиком. Исходный IndexedDB сохраняется при миграции.

Меню страницы и блока дополнены действиями для вложенных страниц, дублирования, перемещения, избранного, корзины, истории и экспорта. Простые таблицы получили операции со строками и столбцами; вкладки — перемещение и удаление. Заготовки таблицы/доски/галереи заменены общей моделью карточек с редактируемыми свойствами.

## Следующие приоритеты

1. **Редактор:** заменить HTML как основной документ полноценным деревом блоков и встроенной моделью выделения. Сейчас есть стабильные идентификаторы и метаданные блоков, но HTML остаётся основным содержимым. Это ограничивает сложное вложение и преобразования; `execCommand` следует заменить поддерживаемым механизмом транзакций.
2. **Базы:** формулы, связи, агрегаты, произвольные фильтры, календарь, обложки карточек и возможность открывать карточку как полноценную блочную страницу. Сейчас описание карточки — обычный текст.
3. **Перенос:** единый формат архива для браузера и Windows, включение истории в архив и просмотр изменений перед слиянием. Сейчас Windows импортирует браузерный JSON, обратный перенос полного `.diary` в браузер не поддерживается.
4. **Удобство:** полностью перевести новые меню, улучшить навигацию с клавиатуры, пересчёт оглавления и ссылки при удалении страниц.
5. **Объём данных:** индекс поиска и фоновые архивы. JSON понятен и переносим, но загрузка списка и архивирование больших хранилищ потребуют оптимизации. При дальнейшем росте можно использовать SQLite, оставив вложения отдельными файлами.
6. **Доставка:** подпись Windows-сборок и проверяемое обновление приложения.

Синхронизация, совместное редактирование, права доступа, публичные страницы и AI потребуют отдельной серверной части и выбора пользователя, куда отправлять записи.

## Проверки выпуска

- Проверка кода и 9 тестов хранилища: миграция, вложения, перенос папки, очередь записи, блокировка второго писателя, пути, архивы, история и повреждённые вложения.
- Изолированная проверка Electron: preload, IPC, сохранение, чтение вложений через внутренний протокол, запрет небезопасных URL и отсутствие Node.js в странице.
- Ручная проверка интерфейса на тестовых записях: автосохранение после перезапуска, галочки, описание/статус карточки, смена представления, поиск, вложенные страницы, корзина, восстановление истории и блокировка редактирования.

Windows выпускается для x64. Производственные зависимости прошли `npm audit --omit=dev` без известных уязвимостей на момент проверки; зависимости инструментов сборки требуют отдельного дальнейшего обновления.
